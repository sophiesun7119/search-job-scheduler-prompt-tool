# Search Job Scheduler Prompt Tool

Generate two personalized scheduler prompts: discover companies and find their open jobs, using your Google Sheet as shared storage.

This repository is being built. The initial scaffold defines scope; prompt templates and usage instructions follow in subsequent commits.

The finished skill will accept plain-language preferences or an editable sample profile and a Sheet link. It will produce `output/find-companies-prompt.md` and `output/find-jobs-prompt.md`, each ready to copy in full into a scheduler after connection setup.

Personal profiles, Sheet links, and generated outputs stay in Git-ignored `local/` and `output/` directories.
